# Memory bank

Everything a person or an agent needs to continue the work without the chat history. Read `activeContext.md`
first, then whatever the task touches.

| File | What it holds | Changes |
|---|---|---|
| [projectbrief.md](projectbrief.md) | what this is, why it exists, who it's for, what success looks like | rarely |
| [productContext.md](productContext.md) | screens, behaviour, metrics, content and licences, accessibility | when product rules change |
| [techContext.md](techContext.md) | stack, network simulation, architecture, player adapter, inspector, media, budgets, tests, risks | when the technical plan changes |
| [activeContext.md](activeContext.md) | current state, decisions waiting for the owner, next step, open questions | every work session |
| [progress.md](progress.md) | milestones with done-criteria and target dates, done log | when a milestone moves |

## Rules

- Update `activeContext.md` and `progress.md` at the end of every work session.
- Write facts, not plans dressed as facts: mark anything not built yet as *planned*.
- Absolute dates (`2026-10-17`), never "yesterday".
- This folder will be public with the repo: no secrets, nothing personal about the owner.
